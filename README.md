## Дружественные функции и перегрузка операторов

## Цель работы
Расширение консольного приложения «Сеть библиотек» средствами дружественных
функций и перегрузки операторов, чтобы работа с объектами записывалась так же
просто, как работа со встроенными типами.

## Структура проекта
`Book.h` / `Book.cpp` — класс «Издание» (ID, название, автор, год издания): операторы `==`, `<=`, `>`, `<<`, `>>`
  и дружественная функция `sameAuthor`.
`Branch.h` / `Branch.cpp` — класс «Филиал»: операторы `+=` и `-=`
  для добавления и удаления книг, методы поиска книг по году издания.
`Main.cpp` — меню пользователя, обработчики команд и функция ввода `readInt`.

## Перегруженные операторы
`==` — сравнение книг по ID (одна и та же книга).
`<=` — сравнение по году издания: год левой книги не больше года правой.
`>` — сравнение по году издания: левая книга издана позже правой.
`<<` — вывод полной информации о книге.
`>>` — ввод названия, автора и года издания книги.
`+=` — добавление книги в филиал.
`-=` — удаление книги из филиала.
`sameAuthor` — дружественная функция, сравнивающая авторов двух книг
  (использует закрытое поле `author`).

## Основной функционал
Просмотр филиалов, добавление и удаление книг, а также 
поиск других книг того же автора, поиск книг, изданных в указанном году, раньше и 
после указанного года в каждом филиале.
  
## Ограничение предметной области
Филиал не может принять книгу, если число хранящихся в нём изданий уже равно
вместимости, и не может удалить книгу, которой в нём нет. В обоих случаях
программа выводит сообщение об ошибке и не изменяет данные.

## Наследование

## Цель работы
Расширение консольного приложения «Сеть библиотек» иерархией классов: вынести общие характеристики изданий в базовый класс и описать виды изданий производными классами, чтобы не дублировать код.

## Структура проекта
`LibraryItem.h` / `LibraryItem.cpp` — базовый класс «Издание» (ID, название, год выпуска): 
геттеры, сеттеры, операторы сравнения, <<, >>.
`Book.h` / `Book.cpp` — класс «Книга» (автор, жанр, число страниц).
`Magazine.h` / `Magazine.cpp` —  класс «Журнал» (тематика, номер выпуска, аудитория).
`Newspaper.h` / `Newspaper.cpp` — класс «Газета» (номер выпуска, тираж, издатель).
`Branch.h` / `Branch.cpp` — класс «Филиал»: каталог изданий, операторы += и -=, методы поиска.

## Иерархия классов
Book, Magazine и Newspaper публично наследуют LibraryItem. Общие данные и методы описаны один раз в базовом классе, 
производные классы добавляют только свои поля и методы. Конструктор производного класса передаёт общие данные 
конструктору базового. Методы getType и getLoanDays переопределены в каждом производном классе.

## Основной функционал
Просмотр филиалов и изданий, информация об издании, добавление и удаление издания, 
поиск других книг того же автора, поиск изданий по году, просмотр сроков выдачи, 
демонстрация наследования (унаследованные поля, сеттер и геттеры).

## Ограничение предметной области
Филиал не может принять издание сверх вместимости и не может удалить издание, 
которого в нём нет. При выборе несуществующего типа издания или филиала данные 
не изменяются, программа выводит сообщение об ошибке.
