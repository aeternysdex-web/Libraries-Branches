## Дружественные функции и перегрузка операторов

## Цель работы
Расширение консольного приложения «Сеть библиотек» средствами дружественных
функций и перегрузки операторов, чтобы работа с объектами записывалась так же
просто, как работа со встроенными типами.

## Структура проекта
`Book.h` / `Book.cpp` — класс «Издание» (ID, название, автор, год издания): операторы `==`, `<=`, `>`, `<<`, `>>`
  и дружественная функция `sameAuthor`.
`Branch.h` / `Branch.cpp` — класс «Филиал»: операторы `+=` и `-=`
  для добавления и удаления книг, методы поиска книг по году издания.
`Main.cpp` — меню пользователя, обработчики команд и функция ввода `readInt`.

## Перегруженные операторы
`==` — сравнение книг по ID (одна и та же книга).
`<=` — сравнение по году издания: год левой книги не больше года правой.
`>` — сравнение по году издания: левая книга издана позже правой.
`<<` — вывод полной информации о книге.
`>>` — ввод названия, автора и года издания книги.
`+=` — добавление книги в филиал.
`-=` — удаление книги из филиала.
`sameAuthor` — дружественная функция, сравнивающая авторов двух книг
  (использует закрытое поле `author`).

## Основной функционал
Просмотр филиалов, добавление и удаление книг, а также 
поиск других книг того же автора, поиск книг, изданных в указанном году, раньше и 
после указанного года в каждом филиале.
  
## Ограничение предметной области
Филиал не может принять книгу, если число хранящихся в нём изданий уже равно
вместимости, и не может удалить книгу, которой в нём нет. В обоих случаях
программа выводит сообщение об ошибке и не изменяет данные.
