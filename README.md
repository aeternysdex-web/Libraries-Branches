## Дружественные функции и перегрузка операторов

## Цель работы
Расширение консольного приложения «Сеть библиотек» средствами дружественных
функций и перегрузки операторов, чтобы работа с объектами записывалась так же
просто, как работа со встроенными типами.

## Структура проекта
`Book.h` / `Book.cpp` — класс «Издание» (ID, название, автор, год издания): операторы `==`, `<=`, `>`, `<<`, `>>`
  и дружественная функция `sameAuthor`.
`Branch.h` / `Branch.cpp` — класс «Филиал»: операторы `+=` и `-=`
  для добавления и удаления книг, методы поиска книг по году издания.
`Main.cpp` — меню пользователя, обработчики команд и функция ввода `readInt`.

## Перегруженные операторы
`==` — сравнение книг по ID (одна и та же книга).
`<=` — сравнение по году издания: год левой книги не больше года правой.
`>` — сравнение по году издания: левая книга издана позже правой.
`<<` — вывод полной информации о книге.
`>>` — ввод названия, автора и года издания книги.
`+=` — добавление книги в филиал.
`-=` — удаление книги из филиала.
`sameAuthor` — дружественная функция, сравнивающая авторов двух книг
  (использует закрытое поле `author`).

## Основной функционал
Просмотр филиалов, добавление и удаление книг, а также 
поиск других книг того же автора, поиск книг, изданных в указанном году, раньше и 
после указанного года в каждом филиале.
  
## Ограничение предметной области
Филиал не может принять книгу, если число хранящихся в нём изданий уже равно
вместимости, и не может удалить книгу, которой в нём нет. В обоих случаях
программа выводит сообщение об ошибке и не изменяет данные.

## Наследование

## Цель работы
Расширение консольного приложения «Сеть библиотек» иерархией классов: вынести общие характеристики изданий в базовый класс и описать виды изданий производными классами, чтобы не дублировать код.

## Структура проекта
`LibraryItem.h` / `LibraryItem.cpp` — базовый класс «Издание» (ID, название, год выпуска): 
геттеры, сеттеры, операторы сравнения, <<, >>.
`Book.h` / `Book.cpp` — класс «Книга» (автор, жанр, число страниц).
`Magazine.h` / `Magazine.cpp` —  класс «Журнал» (тематика, номер выпуска, аудитория).
`Newspaper.h` / `Newspaper.cpp` — класс «Газета» (номер выпуска, тираж, издатель).
`Branch.h` / `Branch.cpp` — класс «Филиал»: каталог изданий, операторы += и -=, методы поиска.

## Иерархия классов
Book, Magazine и Newspaper публично наследуют LibraryItem. Общие данные и методы описаны один раз в базовом классе, 
производные классы добавляют только свои поля и методы. Конструктор производного класса передаёт общие данные 
конструктору базового. Методы getType и getLoanDays переопределены в каждом производном классе.

## Основной функционал
Просмотр филиалов и изданий, информация об издании, добавление и удаление издания, 
поиск других книг того же автора, поиск изданий по году, просмотр сроков выдачи, 
демонстрация наследования (унаследованные поля, сеттер и геттеры).

## Ограничение предметной области
Филиал не может принять издание сверх вместимости и не может удалить издание, 
которого в нём нет. При выборе несуществующего типа издания или филиала данные 
не изменяются, программа выводит сообщение об ошибке.

## Лабораторная работа №4
## Тема: Полиморфизм, виртуальные функции, абстрактные классы

## Цель работы
Расширение иерархии классов изданий сети библиотек механизмами динамического полиморфизма: 
превращение базового класса в абстрактный, реализация виртуальных методов в производных классах 
и единообразная работа с разнотипными объектами через указатель на базовый класс.

## Структура проекта
`LibraryItem.h `/ `LibraryItem.cpp` — абстрактный базовый класс с чисто виртуальными методами (getType(), 
calculateLossCost()), виртуальными методами getLoanDays(), printInfo(), readFrom(), виртуальным деструктором 
и перегруженными операторами сравнения и ввода-вывода.
`Book.h` / `Book.cpp` — производный класс «Книга» (переопределяет виртуальные методы со специфическим параметром — количество страниц).
`Magazine.h` / `Magazine.cpp` — производный класс «Журнал» (переопределяет виртуальные методы со специфическим параметром — номер выпуска).
`Newspaper.h` /`Newspaper.cpp `— производный класс «Газета» (переопределяет виртуальные методы со специфическим параметром — тираж).
`Branch.h` / `Branch.cpp` — класс-менеджер филиала с коллекцией std::vector<std::unique_ptr<LibraryItem>> 
и полиморфными операциями над всеми изданиями (вывод каталога, сроки выдачи, выбор изданий по году через операторы <= и >).
`Main.cpp` — точка входа в программу с интерактивным консольным меню для управления сетью библиотек.

## Основной функционал
Специфическое полиморфное вычисление: метод calculateLossCost() считает выплату за утерю издания 
(базовая цена × коэффициент ценности) — результат полностью зависит от фактического типа объекта.
Полиморфные вызовы: вывод информации об издании (оператор << вызывает полиморфный метод printInfo()), 
ввод издания (оператор >> вызывает readFrom()), вывод сроков выдачи через getLoanDays(),
расчёт выплаты за утерю через calculateLossCost().
Управление временем жизни объектов: владение объектами через умный указатель std::unique_ptr 
(автоматическое безопасное управление памятью без утечек) и виртуальный деструктор (virtual ~LibraryItem() = default) в базовом классе.

## Лабораторная работа №5
## Тема: Шаблоны
 
## Цель работы
Разработка универсального механизма хранения и обработки объектов, не зависящего от типа данных: 
один шаблонный контейнер вместо отдельных хранилищ для каждого класса.
 
## Структура проекта
`Collection.h` — шаблонный контейнер `Collection<T>` (динамический массив из `std::unique_ptr<T>`) и шаблонная функция `printIf()`.
`Branch.h` / `Branch.cpp` — класс «Филиал»: коллекции `Collection<Book>`, `Collection<Newspaper>`, `Collection<Magazine>` и шаблонные методы обработки.
`Main.cpp` — консольное меню; филиалы хранятся в `Collection<Branch>`.
Остальные файлы (`LibraryItem`, `Book`, `Magazine`, `Newspaper`) — иерархия изданий из предыдущих работ.
 
## Шаблонный класс Collection<T>
Контейнер владеет элементами через `std::unique_ptr<T>`, копирование запрещено, ёмкость удваивается при заполнении. 
Методы: `add()` — добавление, `removeAt()` — удаление по индексу, `get()` — получение по индексу, 
`findIndex()` — поиск по предикату, `getCount()` — размер, `clear()` — очистка, `print()` — вывод.
 
## Шаблонные функции
`printIf(list, pred, out)` выводит элементы коллекции любого типа, подходящие под критерий. 
В `Branch` шаблонами реализованы поиск и удаление по ID, а также вывод списков изданий.
 
## Применение к разным типам
`Collection<T>` используется с типами `Book`, `Newspaper`, `Magazine`, `Branch` и `std::string`, 
что показывает независимость реализации от предметной области.
 
## Основной функционал
Всё из лабораторной №4, а также вывод всех книг, которые читатель успеет дочитать (пункт 13), 
газет, которые можно взять домой (пункт 14), и журналов для выбранной аудитории (пункт 15): 
критерии задаются лямбда-выражениями.

## Лабораторная работа №6
## Тема: Обработка исключительных ситуаций

## Цель работы
Расширение программной системы «Сеть библиотек» механизмом обработки исключительных ситуаций: 
собственная иерархия исключений, их генерация в методах, где возникает ошибка, и обработка в главном цикле меню без аварийного завершения программы.

## Структура проекта
`LibraryException.h` / `LibraryException.cpp` — базовый класс исключений библиотеки, наследуется от `std::runtime_error`.
`InvalidDataException`, `LimitExceededException`, `DuplicateException`, `ObjectNotFoundException`, `OutOfRangeException`, `InvalidOperationException`, `RelationException` — семь производных классов, каждый в своей паре файлов (`.h` и `.cpp`).
`Branch.h` / `Branch.cpp`, `Book.cpp`, `Magazine.cpp`, `Newspaper.cpp`, `LibraryItem.h` / `LibraryItem.cpp` — классы, в которых проверяются данные и генерируются исключения.
`Main.cpp` — консольное меню и блоки `try` / `catch`.
Остальные файлы (`Collection.h` и заголовки изданий) — из предыдущих работ.

## Иерархия исключений
`std::exception` → `std::runtime_error` → `LibraryException` → семь типов ошибок. 
В конструкторе каждого класса к тексту добавляется префикс («Некорректные данные: », «Дублирование ID: » и т.д.), 
поэтому по сообщению сразу видно тип ошибки. Общий родитель позволяет перехватить любую ошибку библиотеки одним `catch`.

## Исключительные ситуации
`InvalidDataException` — некорректные данные: ввод не числа (`readNumber`), пустое название, год, число страниц, тираж или номер выпуска ≤ 0 (`readFrom`, `setTitle`), пустое имя или вместимость филиала ≤ 0 (конструктор `Branch`), ID ≤ 0 (`addItem`).
`LimitExceededException` — филиал переполнен (`Branch::operator+=`).
`DuplicateException` — издание с таким ID уже есть в сети (`addItem`) или в филиале (`Branch::operator+=`).
`ObjectNotFoundException` — издание с указанным ID не найдено (`Branch::operator-=`, функции просмотра, изменения и оценки изданий в `Main.cpp`).
`OutOfRangeException` — номер филиала, тип издания или номер аудитории вне допустимого диапазона (`addItem`, `deleteItem`, `deleteBranch`, `Magazine::chooseAudience`).
`InvalidOperationException` — удаление издания из пустого филиала (`Branch::operator-=`), нулевая или отрицательная скорость чтения в `Book::canFinishInLoanPeriod`.
`RelationException` — удаление филиала, в котором ещё есть издания (`deleteBranch`).

## Обработка исключений
Тело главного цикла меню заключено в `try`. После него расположены отдельные блоки `catch` для каждого из семи типов ошибок, 
в каждом — своя подсказка пользователю (например, «Укажите другой ID» при дубликате). 
Затем идут общие обработчики: `LibraryException`, `std::exception` и `catch (...)`. 
Порядок обработчиков — от частных к общим. Исключения перехватываются по константной ссылке.
